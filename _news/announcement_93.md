IBM Research covered ["Every Eval Ever"](https://research.ibm.com/blog/every-evaluation-ever) — a unifying schema and community repository for AI evaluation results, built with a global team including IBM. Nominally identical evaluations can vary by as much as 20 percentage points depending on the harness; as I told IBM, "If we can create a system that is reusable and trustworthy, people don't need to run these expensive evaluations again and again."
